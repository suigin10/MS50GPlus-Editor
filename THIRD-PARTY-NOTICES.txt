Effect parameter and DSP metadata:
Added MS-50G+ IDs, parameter limits/defaults, filenames and DSP metadata were
read from MS-50G+ firmware 1.40, without writing patch data.
Display-value lists from the MIT mappings above are reused only for matching
parameters, with the actual MS-50G+ ranges/defaults verified independently.
DSP values now use the unrounded float32 INFO metadata read from this pedal.
The INFO-to-percent conversion follows zoom-zt2 (dspload / 2.5).
Only factual parameter metadata is distributed. ZD2 executable binaries,
icons, audio data and the manufacturer's descriptive text are not included.
