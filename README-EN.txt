MS50GPlus-Editor v0.7.3 / Windows x64

Extract the entire ZIP to a writable folder and run MS50GPlus-Editor.exe.
Keep the executable with all included files. No separate Node.js, Python
or browser installation is needed. Recovery data and language preferences
are stored in the data folder next to the executable.

User guide: docs/USAGE.en.md
Japanese: docs/USAGE.ja.md
Overview: README.en.md

For MS-50G+. Pedal integration checked with firmware 1.40. Audio is
processed by the pedal. The app is unsigned. Back up patches before editing.
