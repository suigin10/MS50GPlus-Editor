MS50GPlus-Editor v0.7.3 / Windows x64

ZIP全体を書き込み可能なフォルダーへ展開し、MS50GPlus-Editor.exeを起動してください。
実行ファイルだけを取り出さず、同梱ファイルと一緒に使用します。
Node.js、Python、ブラウザーの準備は不要です。
作業の自動復旧データと言語設定は、実行ファイル横のdataフォルダーに保存します。
