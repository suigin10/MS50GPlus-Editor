# 使い方

[READMEへ戻る](../README.md) · [English](USAGE.en.md)

## 接続する

1. MS-50G+をUSBデータケーブルでPCにつなぎます。
2. 「USB接続」でMS-50G+のMIDI入力と出力を選びます。
3. 「接続する」を押すと、本体の現在の音色・導入エフェクト・100件のパッチ名を読み込み、双方向同期がONになります。

音は本体につないだアンプやオーディオインターフェースから聴きます。右上で日本語／Englishを選べます。表示言語は次回起動時も保持され、本体の言語設定は変更しません。

## 音色を調整する

スロットを選び、左のライブラリーからエフェクトを追加・置換します。最大6エフェクトを使えます。スライダー、選択肢、数値欄で調整し、スロットの移動・削除やON/OFFも操作できます。

双方向同期がONのとき、パラメーター・ON/OFF・テンポ・音量はPCと本体で同期します。PCで名前・構成・並び順を変更したときは一時停止するので、「本体に反映」で送信します。手動でOFFにした場合は、必要に応じて同期をONにしてください。

パッチ名は半角英数字・記号28文字までです。日本語のメモはPCのプロジェクトに保存できます。

## パッチを切り替える

上部のPATCH MEMORYで◀／▶、または「パッチ一覧」から選びます。001で◀を押すと100、100で▶を押すと001へ進みます。一覧は番号・名前で検索できます。

選択すると本体の音色も切り替わり、PCに読み込みます。PC上の編集を残す場合は、切り替える前に「PCに保存」を使ってください。

## 保存する

| 操作 | 保存・反映する場所 |
| --- | --- |
| PCに保存 | 音色とメモを`.ms50g.json`ファイルに保存 |
| .zptc 書き出し | メモを含まないパッチデータをファイルに保存 |
| 本体に反映 | PCの設定を本体の現在のパッチに反映 |
| 011 に保存などの番号付きボタン | PATCH MEMORYに表示中の番号へ上書き保存 |

本体への保存では、番号と保存先の既存パッチ名を確認します。本体のAUTO SAVEがONなら、通常の調整内容も本体へ自動保存されます。アプリはAUTO SAVEの設定を変更しません。

「本体のパッチ管理・バックアップ」にある「読み取り番号」は、指定した保存済みパッチをPCに開くための番号です。保存先を変更する欄ではありません。

## Emptyに戻す

上部の「Emptyに戻す」でPCの編集中パッチを初期化します。名前はEmpty、エフェクトなし、テンポ120、音量100、メモなしとなり、同期は停止します。PATCH MEMORYの番号は保持されます。

本体のパッチもEmptyとして保存する場合は、初期化後に番号付き保存ボタンを押します。PC上の初期化は「元に戻す」で取り消せます。

## バックアップ・復元

「本体のパッチ管理・バックアップ」を開き、「全100パッチをバックアップ」でPCへ保存します。中断した場合は取得済みのパッチだけを保存できます。

復元は次の順序で1件ずつ行います。

1. PATCH MEMORYで本体の保存先を選びます。
2. 「開く」でバックアップファイルを選びます。
3. バックアップ内のパッチを選び、「選択したパッチを開く」を押します。
4. 番号付きの保存ボタンで本体へ保存します。

## ライブラリーとDSPバー

カテゴリーの括弧内の数字は導入済み件数です。追加マークは、発売後に公式配信されたエフェクトを示します。エフェクトの導入自体は別途行ってください。

DSPバーは、搭載エフェクトの負荷基準値を合計した推定値です。OFFのエフェクトも合計に含みます。値を取得できないエフェクトは不明として表示します。「DSP値を本体から更新」で基準値を読み直せます。

本体のDSP容量超過表示や利用不可スロットを検出すると、同期を停止します。エフェクトを削除・置換し、本体の状態を確認してください。

## 接続できないとき

USBケーブルのデータ転送対応、本体の電源、MIDI入出力の選択を確認してください。同じ本体を使っているほかのエディターやDAWを閉じ、ポートを再検索します。

## ショートカット

Ctrl+S：PCに保存 / Ctrl+O：開く / Ctrl+Z：元に戻す / Ctrl+Y：やり直し
