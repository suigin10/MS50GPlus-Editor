MS-50G+ Editor · v0.7.3

  1. 接続・調整
    「USB接続」で本体を選ぶと、現在の音色を読み込み、双方向同期がONになります。パラメーター・ON/OFF・テンポ・音量をPCと本体で同期します。同期中にPCで名前や構成を変えた後は「本体に反映」を押します。
  2. パッチの選択
    上のPATCH MEMORYで◀ / ▶ または「パッチ一覧」から選びます。001↔100も循環します。一覧は番号・名前で検索できます。
  3. 保存
    「PCに保存」は音色とメモをPCのファイルに保存します。本体へは「011 に保存」などの番号付きボタンで、PATCH MEMORYに表示中の番号へ保存します。本体のAUTO SAVEがONなら調整内容も自動保存されます。
  4. バックアップ・復元
    「本体のパッチ管理・バックアップ」で全100パッチをPCに保存できます。復元はPATCH MEMORYで保存先を選び、バックアップのパッチを開いて番号付きボタンで保存します。「読み取り番号」はPCへ読み込む番号で、保存先には影響しません。

Emptyに戻す：PCのパッチを初期化します。本体へは番号付きの保存ボタンで保存します。

表示言語：右上で日本語／Englishを切り替えます。次回起動時も保持します。本体の言語設定は変更しません。

DSPバー：エフェクトごとの負荷基準値を合計した推定値です。「DSP値を本体から更新」で取得し直せます。

Windows用・MS-50G+専用。音声処理は本体で行います。
